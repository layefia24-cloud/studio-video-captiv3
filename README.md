# studio-video-captiv

> Usage réservé aux élèves de la formation STUDIO CAPTIV : voir la [licence](LICENSE.md).

Kit du skill **Studio vidéo CAPTIV** : moteur de rendu et look book pour fabriquer des Reels, TikTok, Shorts et vidéos 16:9 (face caméra ou sans visage), avec voix IA, sous-titres et motion design.

- `SKILL.md` : la méthode de travail et les instructions du skill
- `references/` : le look book en codes (`codes.md`), les styles, les cibles, les exemples de configuration et les vignettes de chaque code
- `scripts/` : le moteur (`short.js`, `premium.js`, `render.mjs`, `engine.html`), les outils Python (`guide.py`, `prepare.py`, `tts.py` : voix IA OmniVoice en français et en wolof) et les polices
- `outils/` : outils complémentaires (`OUTILS.md`), le pack video-agent-skills et reanimate (licences MIT)

Installation du moteur : voir la section 3 de `SKILL.md`.
